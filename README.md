# Game Changer Product Repository

## Structure

- `GAME CHANGER/` — corporate Game Changer materials.
- `AG WORLD/` — the AgWorld application, including application code, assets, data, database material, documentation and brand assets.

Repository-root files are limited to shared repository/deployment infrastructure and compatibility entry points required by existing hosting services.

## Official AgWorld V1 baselines

The current approved screen baselines are documented inside `AG WORLD/`:

- `V1_BASELINE_TECHNICAL_SPEC.md` — full Login Screen V1 and Player Screen V1 technical specification, geometry and component ownership.
- `PLAYER_SCREEN_V1_BASELINE.md` — locked Player Screen V1 geometry and change-control rules.
- `CODEBASE_AUDIT_AND_HARDENING_20260910.md` — code audit, stale-layer stock take, cleanup status and production hardening roadmap.
- `ARCHITECTURE_AUDIT.md` — longer-term architecture migration direction.

These baselines are the reference point for future development. New component work must preserve the approved screen-level geometry unless a new version is explicitly approved.
