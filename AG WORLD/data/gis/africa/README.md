# AgWorld regional board data

The opening view displays the 16 SADC countries. The wider Africa control exposes all 48 sub-Saharan country records. Country flags and outlines share the same selection action. First administrative divisions load per country from local files.

Country polygons: Natural Earth 1:50m, public domain. Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson

Administrative divisions: geoBoundaries gbOpen, pinned release 9469f09. Per-country original downloads, dates, sources and licenses are retained in index.json. See attribution.html for the player-facing credits and source links. Derived geometry retains the source licensing, including ODbL share-alike where specified. The distributed files provide the full derived boundary dataset in GeoJSON.

Geometry uses Douglas–Peucker simplification (0.004 degrees for country outlines, 0.008 degrees for divisions; a few larger features are simplified further) and four-decimal coordinates. MultiPolygon islands and interior rings are preserved. This is a gameplay cartographic snapshot, not a claim of current legal boundary authority.

Flags: https://github.com/lipis/flag-icons (MIT, see FLAG-LICENSE.txt). SADC membership: https://www.sadc.int/member-states (accessed 2026-09-12).
