# AgWorld Colour System

## Source-of-truth hierarchy

1. **Digital products:** HEX values are authoritative.
2. **RGB:** use for digital systems that require RGB entry.
3. **HSL:** use where a design or CSS system works in HSL.
4. **CMYK:** practical process-print conversion; obtain a physical proof for critical print.
